Cairo-Files-Android — GitHub patch

Upload the CONTENTS of this folder to the ROOT of the existing GitHub repository.

Included:
- .github/workflows/android.yml
- .github/workflows/generate-wrapper.yml
- .gitignore
- .env.example
- app/build.gradle.kts

After uploading:
1) Open GitHub > Actions.
2) Android CI can build immediately without the missing wrapper files.
3) To add the official Gradle Wrapper files, run "Generate Gradle Wrapper" once.
   It will generate and commit:
   - gradlew
   - gradlew.bat
   - gradle/wrapper/gradle-wrapper.jar
   - gradle/wrapper/gradle-wrapper.properties

The app/build.gradle.kts patch also removes the hard dependency on a committed debug.keystore.
